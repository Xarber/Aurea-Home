# Aurea incident response

Classify public web or signaling outages as SEV2 when alternative local control still works, and escalate a confirmed credential compromise or major data loss to SEV1. Capture the affected endpoint, deployment commit and sanitized failure evidence. Check whether the failure is in TLS, static assets, signaling or a device connection before intervening. Roll back only the affected component, verify a fresh pairing or relevant core flow, and record recovery time and regression coverage.
