# Aurea 2.4 device test checklist

Use the GitHub Actions **testing** artifacts for the source revision reported with the run. These are verification packages. The Android TV Home and Android phone Remote have different APKs. Use the matching APK to update an installed copy. Stop if Android reports a signing mismatch and preserve the installed app and data. AABs are for distribution tooling. The unsigned iOS IPA requires the usual compatible signing workflow. The iOS simulator bundle runs only in Simulator.

## Run first on your TV and one phone

| Check | What to try | Expected result |
| --- | --- | --- |
| Update and startup | Upgrade the current TV install, reopen Home, and reboot the TV once. Use About to confirm 2.4.0. | Same apps, dock, paired devices and receiver settings. Home returns after boot. What's New appears once. Recovery Home remains under Developer Options. |
| Control regression | Move around the dock and Control Center with both the physical or existing TV remote and Aurea Remote. Open a settings submenu, back out, switch HDMI and Live TV, and return Home from a streaming app. | One move per click. Settings Back returns to the parent. Port names and logos are correct. Saved native phone system controls work outside Aurea on compatible TVs. |
| Account sign-in | Open Account on the TV, iPhone, Android phone and hosted web when the matching web version is available. Finish the TV handoff with a phone browser. Try both a platform passkey and an enrolled physical FIDO2 key in the system browser if available. | Each completes its own sign-in. Cancel returns safely. A restart preserves a session when staying signed in was chosen. Sign-out revokes the relevant session. |
| Household pairing | Sign in to the same X-Center ID on a TV profile and an unpaired phone or browser. Enable automatic account pairing on that TV profile and make the remote idle on its TV screen. Repeat with an alternate account or the toggle off. | The verified same-account TV can pair without a PIN in the opted-in case. The alternate account cannot claim it. PIN-based manual pairing remains usable. |
| Profile isolation | Create a second profile, link a different account, change its wallpaper and dock, and switch back. Try linking the same account to both profiles. Back up and restore a harmless wallpaper change. Open Kids and try leaving without the PIN. | Settings remain separate. Duplicate linking is refused. Backup applies to the intended profile. Kids blocks the configured apps and requires the parent PIN to exit. |
| AirPlay and Apple TV | AirPlay Spotify from iPhone to Aurea. Play, pause, and resume. Try mirroring, then test the paired Apple TV app list, navigation and Music on its actual HDMI. Test receiver rename, disable and re-enable. | Audio can play without covering Home and its activity appears, then disappears after five minutes paused. Mirroring uses full screen. Changing the receiver does not remove the paired Apple TV connection. |
| Native phone system controls | Open a streaming app outside Home. Use D-pad, Home, back, playback, volume and mute. Open a TV search field and type/delete. Start and stop the microphone twice. Switch between saved TVs. | Each command reaches the selected TV once. Keyboard appears for supported fields and sends as you type. Voice works twice without stalling. A saved system connection can work while Home is unavailable. |

## Then test the new options you use

| Area | What to try |
| --- | --- |
| Appearance and accessibility | Use Daylight with the TV clock and a chosen city. Verify a phase change and weather overlay. Import a private image and video, switch profiles, then try rotation, idle dimming, optional focus tilt, Reduced Motion, quiet hours, and black cover while audio plays. Press a remote key to wake. Check English and Italian, long settings text, and focus in scrollable panels. |
| Viewing | Play an app that publishes Android Watch Next rows. Check progress, resume, dismissal and filters. Import a small test Netflix CSV and YouTube Takeout file. Try TMDB title search and availability, Plex Continue Watching, Stremio and a selected Android music session. For two paired TVs, send a title and schedule a coordinated start, confirm the match on both TVs, and try canceling. Exact progress transfer is not part of this candidate. |
| Household tools | Create a local list, calendar entry, countdown, anniversary and recurring collection reminder. Scan an example guest Wi-Fi QR. In the primary profile, try TV screen time with usage permission off, then through the official Android settings if you want to grant it. Confirm the report is unavailable on other profiles and the remote. |
| Home Assistant | Add the TV via the integration and verify Home, a benign input change, volume and revocation. In Aurea, select harmless devices. Test supported actions, sensor values, a camera you control, a calendar and optionally AI Task viewing suggestions. Verify denied or unreachable services show a recoverable error. |
| Homebridge | Add the integration to a test bridge, then open Apple Home and verify TV accessory state, sources and volume. Revoke its independent TV key and confirm Homebridge loses control while Home Assistant still works. |
| Web and installation | On the account-enabled web build, check first visit, landing return, sign-in, local or hosted remote pairing, keyboard navigation, and installing the PWA. Existing visitors should go directly to the app. On first-run phone and TV installs available in isolated test environments, finish or skip onboarding and check that it does not repeat. Do not clear production app data to test onboarding. |
| Roku, if available | Save a Roku with mobile app control enabled. Verify navigation and supported playback, volume, and power actions from a native phone. Confirm switching to a second device does not send commands to the first. |

If something fails, note the app version, platform, the menu or app, steps and visible result. Omit PINs, keys, account credentials and private network details. Attach only a cropped screenshot or sanitized diagnostics where useful.
